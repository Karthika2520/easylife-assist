# EasyLife

An accessibility-first digital assistance platform designed for elderly users aged 60+.

## Problem

Many elderly users face difficulties using modern digital platforms because of small text, complicated navigation, confusing terminology, typing difficulties, language barriers, and difficulty accessing important services quickly.

## Solution

EasyLife provides a simple, elderly-friendly interface with large touch targets, readable typography, voice assistance, reminders, emergency support, simple explanations, and Tamil + English language support.

## Features

- 🎤 Voice-first interaction
- 🔊 Read Aloud
- 💊 Medication & appointment reminders
- 🆘 Emergency SOS
- 💡 Explain This
- 👨‍👩‍👧 Family Connect
- 🔠 Adjustable text size
- 🌗 High-contrast mode
- 🇬🇧 English + Tamil
- 📱 Mobile and tablet friendly
- 🧭 Simple single-column navigation

## Tech Stack

- React
- JavaScript
- HTML5
- CSS3
- Web Speech API
- SpeechSynthesis API
- LocalStorage
